Bangla-Specific Advantage

BanglaBERT and BanglishBERT outperform multilingual counterparts (mBERT and XLM-RoBERTa) by +2.22 percentage points Macro-F1, supporting the value of Bangla-specific pretraining over generic multilingual capacity. Caveat: the TF-IDF baseline still leads all six models on Macro-F1 (0.6341), so this gap is a transformer-vs-transformer comparison, not evidence that BERT is the best choice here.

The Negation Deficit

Non-negated reviews achieve 85.69% accuracy, whereas negated reviews drop to 65.59% (a 20.10% deficit). Post-verbal negation (ভালো না) accounts for majority of false positives.

BanglaGEC Ablation — Negative Result

Removing the mined grammar rules raises test Macro-F1 from 0.5985 to 0.6228 (+2.43 pp) — the rules hurt this task, because 51.47% of them are lexical_substitution rewrites that smooth away sentiment-bearing colloquialisms. ⚠️ Not epoch-matched (1 vs 2 epochs), so treat the magnitude as an upper bound. Engineering Rigor

End-to-End System Architecture

How three auxiliary datasets (BanglaGEC, bangla-nlp-words, bangla-nlp-catalog) empower sentiment classification without carrying sentiment labels themselves.

01

Grammar Rule Mining

nahidhub/banglagec

Mines frequent source→target substitution patterns (support ≥ 5) from 7.07M sentence pairs to normalize social media typos before classification.

2,238 high-support rules mined
02

Negation Scope Tagging

saifsunny/bangla-nlp-words

Compiles a 14-negator lexicon. Tokens falling within a 3-token window are prefixed with NEG_ so transformers explicitly attend to polarity inversion.

13.4% reviews carry negation
03

Harmonisation & Split

RevBangla ↗ Daraz ↗ LargeSent ↗

Maps star ratings and labels onto canonical 3-class scheme. Stratifies strictly on (label, source) with 0 text leakage across partitions.

Train: 5,797 • Val: 1,388 • Test: 1,388
04

Discriminative Fine-Tuning

csebuetnlp/banglabert

Pretrained backbone at 2e-5, random classifier head at 6e-5. Uses inverse-frequency class weights, early stopping on macro-F1, and label smoothing 0.05.

Weighted cross-entropy optimization
